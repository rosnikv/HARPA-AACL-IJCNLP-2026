Title

BC-MultiAttn: A Multi-Modal Transformer for Improved Breast Cancer Prognosis Prediction

Introduction

Problem Statement

Current deep learning models for breast cancer prognosis prediction often struggle to effectively integrate diverse data types (gene expression, clinical data, imaging) and capture complex interactions between them. This limits their ability to accurately predict patient outcomes and provide personalized treatment recommendations.

Motivation

Existing approaches typically use separate networks for each data modality or simple concatenation, limiting their ability to model cross-modal relationships. Inspired by recent advances in multi-modal transformers for vision-language tasks, we propose adapting this architecture for integrating heterogeneous cancer data to improve prognostic accuracy. The multi-head attention mechanism in transformers allows for joint attention to information from different representation subspaces and positions, which we hypothesize will better capture complex interactions between gene expression, clinical features, and imaging data.

Proposed Method

We introduce BC-MultiAttn, a novel multi-modal transformer architecture for breast cancer prognosis prediction. The model consists of separate encoder branches for gene expression data, clinical features, and histopathology images. Each branch uses self-attention to capture intra-modality relationships. A cross-modal attention module then allows each modality to attend to relevant information in the others. We introduce a novel gene-clinical interaction layer that explicitly models pairwise interactions between gene expression levels and clinical variables. The model is trained end-to-end using a multi-task objective, jointly optimizing for survival prediction and intrinsic subtype classification. We employ curriculum learning, starting with easier samples and gradually increasing difficulty based on censoring and follow-up time. To improve interpretability, we incorporate an explanation module that generates natural language rationales for predictions by attending to the most salient input features.

Experiments Plan

Step-by-Step Experiment Plan

Step 1: Data Preparation

Obtain and preprocess the METABRIC and TCGA-BRCA datasets. For gene expression data, use the top 1000 most variable genes. For clinical data, encode categorical variables and normalize continuous variables. For histopathology images, use pre-extracted features from a pre-trained CNN (e.g., ResNet50).

Step 2: Model Implementation

Implement the BC-MultiAttn model using PyTorch. Create separate encoder branches for each data modality, implement the cross-modal attention module, and the gene-clinical interaction layer. Use the HuggingFace Transformers library for the transformer components.

Step 3: Training Setup

Implement the multi-task loss function combining survival prediction (using negative log partial likelihood) and subtype classification (using cross-entropy loss). Set up the curriculum learning strategy, starting with samples having longer follow-up times and gradually including more difficult samples.

Step 4: Baseline Models

Implement baseline models including Cox proportional hazards, random survival forests, and DeepSurv. Use the lifelines library for Cox PH and the scikit-survival library for random survival forests.

Step 5: Training and Evaluation

Train the BC-MultiAttn model and baselines on the METABRIC dataset. Use 5-fold cross-validation. Evaluate models using concordance index (C-index) and time-dependent AUC at 5 and 10 years. Use the TCGA-BRCA dataset as an independent test set.

Step 6: Ablation Studies

Conduct ablation studies by removing key components of BC-MultiAttn (e.g., cross-modal attention, gene-clinical interaction layer) to assess their impact on performance.

Step 7: Interpretability Analysis

Generate natural language explanations for a subset of predictions. Compare the learned feature interactions with known gene-phenotype associations from literature (e.g., using the DisGeNET database).

Step 8: Statistical Analysis

Perform statistical tests (e.g., paired t-tests) to compare the performance of BC-MultiAttn against baselines. Calculate confidence intervals for performance metrics.

Step 9: Visualization

Create visualizations of attention weights and feature importance scores to provide insights into the model's decision-making process.

Test Case Examples

Baseline Model Input

Patient data: Age: 55, Tumor size: 2.5cm, Grade: 2, ER status: Positive, PR status: Negative, HER2 status: Negative, Top 5 gene expression values: {BRCA1: 0.8, TP53: 1.2, MKI67: 0.9, ESR1: 1.5, ERBB2: 0.3}

Baseline Model Expected Output

5-year survival probability: 0.82, 10-year survival probability: 0.65

Baseline Model Explanation

The Cox proportional hazards model provides survival probabilities but doesn't capture complex interactions between features or provide detailed explanations.

Proposed Model Input

Same patient data as above, plus histopathology image features

Proposed Model Expected Output

5-year survival probability: 0.78, 10-year survival probability: 0.61, Predicted subtype: Luminal B, Explanation: The model predicts a slightly worse prognosis than the baseline due to the interaction between high MKI67 expression (indicating high proliferation) and negative PR status. The histopathology features suggest a more aggressive tumor morphology, consistent with Luminal B subtype. The positive ER status and high ESR1 expression indicate potential benefit from hormonal therapy.

Explanation

BC-MultiAttn provides more nuanced predictions by capturing complex interactions between multi-modal data. It also offers interpretable explanations, linking molecular and clinical features to the predicted outcome and subtype.

Fallback Plan

If BC-MultiAttn doesn't significantly outperform baselines, we can pivot to an analysis paper focusing on the challenges of integrating multi-modal data for cancer prognosis prediction. We would conduct a comprehensive error analysis to identify which types of patients or data modalities are most challenging for the model. We could investigate whether certain subgroups of patients benefit more from the multi-modal approach. Additionally, we could explore alternative attention mechanisms or neural architecture search to optimize the model structure. Another direction could be to focus on the interpretability aspects, analyzing how the model's attention patterns and feature interactions align with known biological mechanisms in breast cancer. This could provide valuable insights for future model development and potentially uncover novel biomarker combinations.
