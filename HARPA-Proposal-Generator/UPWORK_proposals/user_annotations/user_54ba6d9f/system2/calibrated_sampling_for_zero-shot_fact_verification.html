Title

Calibrated Sampling for Zero-Shot Fact Verification: Leveraging WikiBio Data to Improve LLM Factual Accuracy

Introduction

Problem Statement

Existing fact verification methods for large language models (LLMs) often rely on labeled training data or external knowledge bases, limiting their applicability in zero-resource settings. This research aims to develop a novel approach that improves fact verification without requiring labeled data or external resources, making it suitable for zero-shot scenarios.

Motivation

Current approaches typically use retrieval-augmented generation or fine-tuning on labeled datasets, which are not suitable for zero-shot scenarios. By leveraging the inherent knowledge within LLMs and the structured nature of WikiBio data, we can develop a sampling-based method that improves fact verification without requiring labeled data or external resources. This approach is inspired by the idea that LLMs can generate plausible variations of biographical facts, which can be used to create a probability distribution over possible facts and assess the likelihood of a given claim.

Proposed Method

We introduce Calibrated Sampling for Zero-Shot Fact Verification (CSZFV), which uses WikiBio data to generate multiple plausible variations of biographical facts. For a given claim, CSZFV prompts the LLM to generate N alternative versions of the claim, each with slight variations in entities, dates, or other factual details. These variations are then used to create a probability distribution over possible facts. The LLM is then prompted to rate the likelihood of each variation, including the original claim. By comparing the likelihood of the original claim to the distribution of generated alternatives, we can assess its factual accuracy. To calibrate this process, we use a small set of known true and false claims from WikiBio to adjust the decision threshold dynamically. This calibration step helps account for the LLM's inherent biases and improves the reliability of the fact-checking process.

Experiments Plan

Step-by-Step Experiment Plan

Step 1: Data Preparation

Extract a diverse set of biographical claims from the WikiBio dataset. Create a test set of 1000 claims, with 500 true claims directly from WikiBio and 500 false claims by introducing errors in the true claims (e.g., changing dates, names, or locations).

Step 2: Implement CSZFV

a) Develop a prompt template for generating N alternative versions of a given claim. Example prompt: 'Generate {N} alternative versions of the following biographical claim, each with slight variations in entities, dates, or other factual details: {claim}'
b) Create a prompt template for rating the likelihood of each variation. Example prompt: 'Rate the likelihood of the following biographical claim on a scale of 1 to 10, where 1 is extremely unlikely and 10 is extremely likely: {claim}'
c) Implement the calibration process using a small set of 100 known true and 100 known false claims from WikiBio.

Step 3: Baseline Implementation

Implement two zero-shot baselines: a) Direct prompting: Ask the LLM to classify the claim as true or false. Example prompt: 'Is the following biographical claim true or false? {claim}'
b) Chain-of-thought reasoning: Ask the LLM to reason about the claim before classifying it. Example prompt: 'Consider the following biographical claim: {claim}. Reason step-by-step about its plausibility, then classify it as true or false.'

Step 4: Model Selection

Use GPT-3.5 (text-davinci-003) and GPT-4 from the OpenAI API for all experiments.

Step 5: Experiment Execution

a) For each claim in the test set, run the CSZFV method with N=5, 10, and 20 alternative versions.
b) Run the two baseline methods on the same test set.
c) For CSZFV, experiment with different decision thresholds based on the calibration process.

Step 6: Evaluation

a) Calculate precision, recall, and F1 scores for CSZFV and the baselines.
b) Analyze the impact of N (number of alternative versions) on performance.
c) Evaluate the effectiveness of the calibration process by comparing results with and without calibration.

Step 7: Error Analysis

Manually review a sample of 100 misclassified claims to identify patterns in errors and potential areas for improvement.

Fallback Plan

If the proposed CSZFV method does not significantly outperform the baselines, we can explore several alternative directions. First, we could analyze the generated alternative claims to understand if they are sufficiently diverse and relevant. If not, we might need to refine our prompting strategy to encourage more meaningful variations. Second, we could investigate the likelihood ratings to see if they are consistent and informative. If the LLM struggles to differentiate between true and false claims, we might need to explore different prompting techniques for the rating step. Additionally, we could turn this into an analysis paper by conducting a thorough investigation of how LLMs generate and evaluate factual claims in zero-shot settings. This could involve examining the types of errors made by different models, the impact of claim complexity on verification accuracy, and the potential biases in the models' factual knowledge. Finally, we could explore combining CSZFV with lightweight retrieval methods, using the generated alternatives as queries to improve fact verification without full-scale retrieval-augmented generation.
