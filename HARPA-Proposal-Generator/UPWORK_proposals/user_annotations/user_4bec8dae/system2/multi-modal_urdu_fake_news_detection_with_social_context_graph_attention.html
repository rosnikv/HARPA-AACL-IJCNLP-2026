Title

Multi-Modal Graph Attention Network for Urdu Fake News Detection

Introduction

Problem Statement

Current Urdu fake news detection models ignore crucial visual and social context information that can provide important cues for identifying misinformation. This limits their ability to accurately detect fake news in real-world scenarios where news items often contain multiple modalities of information and spread through complex social networks.

Motivation

Existing approaches focus solely on text content using traditional NLP techniques or basic deep learning models. However, fake news often leverages manipulated images or exploits specific sharing patterns on social media. By incorporating multi-modal information and modeling the social propagation patterns of news, we can significantly improve fake news detection accuracy. This approach aligns with how humans naturally assess the credibility of news by considering not just the text, but also accompanying visuals and the source/spread of information.

Proposed Method

We propose a novel multi-modal graph attention network for Urdu fake news detection. The model consists of three main components: 1) A text encoder using a pre-trained Urdu language model (e.g., UrduBERT) to process the textual content. 2) An image encoder using a vision transformer (e.g., ViT) to extract features from accompanying images. 3) A graph attention network to model social propagation patterns, where each news item is a node in the graph, with edges representing social connections and sharing patterns. These components will be jointly trained end-to-end to classify news as real or fake. The graph attention mechanism allows the model to focus on the most relevant social connections and propagation patterns for each news item, improving overall detection accuracy.

Experiments Plan

Step-by-Step Experiment Plan

Step 1: Dataset Creation

Create a large-scale dataset of Urdu news posts from social media platforms like Twitter and Facebook. Collect text content, accompanying images, and social context information (user profiles, sharing patterns, timestamps, etc.). Annotate a subset of this data for ground truth labels (real/fake) using expert fact-checkers or by cross-referencing with reputable news sources.

Step 2: Data Preprocessing

Clean and preprocess the text data, including tokenization, removing special characters, and handling Urdu-specific linguistic features. Resize and normalize the images. Create a graph structure where each news item is a node, and edges represent social connections or sharing patterns.

Step 3: Model Implementation

Implement the multi-modal graph attention network using PyTorch. Use the Hugging Face Transformers library to load a pre-trained UrduBERT model for the text encoder. Implement the image encoder using a pre-trained ViT model. Implement the graph attention network using the PyTorch Geometric library.

Step 4: Training

Split the dataset into training, validation, and test sets. Train the model end-to-end using cross-entropy loss for the binary classification task (real/fake). Use Adam optimizer with learning rate scheduling. Implement early stopping based on validation performance.

Step 5: Baseline Models

Implement text-only baselines for comparison: 1) A simple LSTM-based model, 2) A fine-tuned UrduBERT model, 3) A state-of-the-art Urdu fake news detection model from recent literature.

Step 6: Evaluation

Evaluate all models on the test set using accuracy, precision, recall, F1-score, and AUC-ROC as metrics. Perform ablation studies to assess the impact of each modality (text, image, graph) and the graph attention mechanism.

Step 7: Analysis

Conduct error analysis to identify types of fake news that are still challenging for the model. Visualize attention weights to interpret which parts of the text, image, and graph structure the model focuses on for its decisions.

Step 8: Robustness Testing

Test the model's performance on out-of-distribution data, such as news from a different time period or from a different social media platform, to assess generalization capabilities.

Explanation

The text-only LSTM model fails to correctly classify the news as fake, likely due to its inability to capture complex linguistic nuances. The fine-tuned UrduBERT performs better but still with relatively low confidence. Our proposed multi-modal graph attention model correctly classifies the news as fake with high confidence, leveraging not just the text but also the accompanying image (which might show signs of manipulation) and the social propagation patterns (which might indicate suspicious sharing behavior typical of fake news).

Fallback Plan

If the proposed multi-modal graph attention model doesn't significantly outperform the baselines, we can explore several alternatives. First, we could conduct a thorough analysis of each component (text, image, graph) to understand which parts are underperforming. This could lead to targeted improvements, such as using a more sophisticated Urdu language model or a better image feature extractor. We could also experiment with different graph construction methods, such as using weighted edges based on user interaction strength or incorporating temporal information into the graph structure. If the multi-modal approach still doesn't yield improvements, we could pivot to an ensemble method, combining predictions from separate text, image, and graph models. This could provide insights into which modalities are most informative for different types of fake news. Additionally, we could focus on creating a more comprehensive and cleaner dataset, as the quality of multi-modal data is crucial for the success of such models. Finally, we could explore transfer learning approaches, pre-training our model on a larger English fake news dataset and then fine-tuning on the Urdu dataset to leverage cross-lingual knowledge transfer.
