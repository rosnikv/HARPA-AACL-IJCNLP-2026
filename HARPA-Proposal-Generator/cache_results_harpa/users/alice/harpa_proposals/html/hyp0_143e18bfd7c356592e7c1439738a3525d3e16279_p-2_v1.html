Title

Integrating Self-Evolving Curriculum with Adaptive Difficulty Learning to enhance LLM reasoning on complex tasks.

Introduction

Motivation

The source paper is Paper 0: Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model? (185 citations, 2025). This idea builds on a progression of related work Paper 1 --> Paper 2.

The analysis of the related papers reveals a trend towards minimizing reliance on external data in RLVR, with the Absolute Zero paradigm and 1-shot RLVR demonstrating significant advancements in this area. However, these approaches primarily focus on data efficiency and do not address the core issue identified in the source paper: the inability of current RLVR methods to elicit fundamentally new reasoning patterns beyond the base model. To advance the field, a research idea should focus on developing a novel RLVR paradigm that not only reduces data dependency but also enhances the reasoning capabilities of LLMs by introducing new reasoning patterns.

Hypothesis

Integrating a Self-Evolving Curriculum using a non-stationary Multi-Armed Bandit framework with Adaptive Difficulty Curriculum Learning will enhance the reasoning capabilities of LLMs on complex mathematical tasks, leading to improved performance on benchmarks like MATH500 compared to using either method alone.

Research Gap

Current RLVR methods often fail to elicit fundamentally new reasoning patterns, as they primarily optimize existing strategies without introducing novel capabilities. This hypothesis addresses the gap by exploring the integration of a Self-Evolving Curriculum using a non-stationary Multi-Armed Bandit framework with Adaptive Difficulty Curriculum Learning to dynamically adjust problem difficulty based on the model's evolving capabilities.

Hypothesis Elements

Independent variable: Integration of Self-Evolving Curriculum using a non-stationary Multi-Armed Bandit framework with Adaptive Difficulty Curriculum Learning

Dependent variable: Reasoning capabilities of LLMs on complex mathematical tasks, measured by accuracy on MATH500 benchmark and problem-solving efficiency

Comparison groups: Models trained with integrated SEC+ADCL approach vs. models trained with SEC only vs. models trained with ADCL only

Baseline/control: Self-Evolving Curriculum (SEC) only and Adaptive Difficulty Curriculum Learning (ADCL) only

Context/setting: Training LLMs on mathematical reasoning tasks using the MATH500 benchmark dataset

Assumptions: The Difficulty Shift phenomenon exists and can be addressed by periodically re-estimating problem difficulty; immediate learning gains can be measured using absolute advantage from policy gradient methods

Relationship type: Causal - the integration of SEC and ADCL will cause enhanced reasoning capabilities

Population: Large Language Models (LLMs)

Timeframe: Duration of curriculum iterations (5 iterations for mini-pilot, 20 for pilot, 100 for full experiment)

Measurement method: Accuracy on MATH500 benchmark (primary metric) and problem-solving efficiency measured by number of attempts required (secondary metric)

Proposed Method

Overview

This research explores the integration of a Self-Evolving Curriculum (SEC) with Adaptive Difficulty Curriculum Learning (ADCL) to enhance the reasoning capabilities of large language models (LLMs) on complex mathematical tasks. The SEC is implemented using a non-stationary Multi-Armed Bandit (MAB) framework, where each problem category is treated as an individual arm. The curriculum policy dynamically selects problem categories that maximize immediate learning gains, measured using the absolute advantage from policy gradient methods. The selection process is guided by a Boltzmann distribution for sampling, and the curriculum policy is updated using the TD(0) method. ADCL addresses the Difficulty Shift phenomenon by periodically re-estimating problem difficulty within upcoming data batches to maintain alignment with the model's evolving capabilities. This integration aims to ensure that the model is consistently challenged with appropriately difficult tasks, facilitating effective learning and generalization. The hypothesis will be tested on the MATH500 benchmark, comparing the performance of models trained with the integrated approach against those trained with each method individually. The expected outcome is that the integrated approach will lead to improved reasoning capabilities, as measured by accuracy and problem-solving efficiency, due to the synergistic effects of dynamic curriculum adjustment and adaptive difficulty alignment.

Background

Self-Evolving Curriculum: The Self-Evolving Curriculum (SEC) is implemented using a non-stationary Multi-Armed Bandit (MAB) framework. Each problem category, such as difficulty level or problem type, is treated as an individual arm. The curriculum policy dynamically selects problem categories to maximize immediate learning gains, which are measured using the absolute advantage from policy gradient methods. The selection process is guided by a Boltzmann distribution for sampling, and the curriculum policy is updated using the TD(0) method. This approach allows the curriculum to adapt to the model's evolving capabilities by adjusting the difficulty of the problems presented during training. The SEC framework is expected to improve reasoning capabilities across diverse domains by enabling better generalization to harder, out-of-distribution test problems.

Adaptive Difficulty Curriculum Learning: Adaptive Difficulty Curriculum Learning (ADCL) involves dynamically adjusting the difficulty of training tasks based on the model's evolving capabilities. This strategy tackles the Difficulty Shift phenomenon by periodically re-estimating difficulty within upcoming data batches to maintain alignment with the model's learning progress. Implementation requires a system that can assess the model's current performance and adjust the curriculum accordingly, often using a teacher model to guide the process. This approach ensures that the model is consistently challenged, promoting deeper understanding and better generalization. ADCL is expected to enhance performance on complex reasoning benchmarks by ensuring that the model is consistently challenged with appropriately difficult tasks.

Experiment Overview

This experiment will compare three curriculum learning approaches for training LLMs on mathematical reasoning tasks:
1. Self-Evolving Curriculum (SEC) only (Baseline 1)
2. Adaptive Difficulty Curriculum Learning (ADCL) only (Baseline 2)
3. Integrated SEC+ADCL approach (Experimental)

The experiment should evaluate these approaches using the MATH500 benchmark dataset, measuring both accuracy (primary metric) and problem-solving efficiency (secondary metric).

Pilot Mode Settings

Implement a global variable PILOT_MODE with three possible settings: 'MINI_PILOT', 'PILOT', or 'FULL_EXPERIMENT'.

  • MINI_PILOT: Use only 10 problems from each category in MATH500 for training and 5 problems for evaluation. Run for only 5 curriculum iterations. This should complete in under 10 minutes and is for code verification only.
  • PILOT: Use 50 problems from each category for training and 20 problems for evaluation. Run for 20 curriculum iterations. This should complete in 1-2 hours and is to verify if the experimental approach shows promise compared to baselines.
  • FULL_EXPERIMENT: Use the complete MATH500 dataset with proper train/validation/test splits and run for the full 100 curriculum iterations.

The experiment should first run in MINI_PILOT mode, then if successful, run in PILOT mode. It should NOT automatically proceed to FULL_EXPERIMENT mode (this will be manually triggered after human verification of pilot results).

Dataset Preparation

  2. Categorize problems by both difficulty level (1-5) and problem type (algebra, geometry, calculus, etc.).
  3. Create appropriate train/validation/test splits (80/10/10) for each pilot mode.

Implementation Details

Self-Evolving Curriculum (SEC) Implementation

  1. Implement a non-stationary Multi-Armed Bandit framework where each problem category (combination of difficulty level and problem type) is treated as an arm.
  2. Initialize Q-values for each arm (category) to 0.
  3. For each curriculum iteration:
    a. Select a problem category using Boltzmann distribution sampling based on current Q-values.
    b. Present problems from the selected category to the LLM.
    c. Measure the learning gain (absolute advantage) from the LLM's performance on these problems.
    d. Update the Q-value for the selected category using the TD(0) method: Q(a) ← Q(a) + α[r - Q(a)], where r is the learning gain and α is the learning rate.

Adaptive Difficulty Curriculum Learning (ADCL) Implementation

  1. Initialize a difficulty estimator for each problem in the dataset.
  2. For each curriculum iteration:
    a. Assess the model's current performance level.
    b. Re-estimate the difficulty of problems in the upcoming batch based on recent performance.
    c. Select problems that are slightly above the model's current capability level.
    d. Update difficulty estimates based on the model's performance on the selected problems.

Integrated SEC+ADCL Implementation

  1. Implement both SEC and ADCL components as described above.
  2. For each curriculum iteration:
    a. Use SEC to select the problem category.
    b. Within the selected category, use ADCL to choose specific problems that match the appropriate difficulty level for the model's current capabilities.
    c. Update both the SEC Q-values and ADCL difficulty estimates based on performance.

LLM Configuration

  1. Use a consistent LLM across all conditions (e.g., GPT-4 or another suitable model).
  2. Implement a standardized prompting strategy for presenting mathematical problems.
  3. Track the number of attempts required to solve each problem correctly.

Evaluation Metrics

  1. Primary Metric: Accuracy on the MATH500 benchmark (percentage of problems solved correctly).
  2. Secondary Metric: Problem-solving efficiency (average number of attempts required to solve problems).
  3. Learning Curve: Plot accuracy over curriculum iterations to visualize learning progress.
